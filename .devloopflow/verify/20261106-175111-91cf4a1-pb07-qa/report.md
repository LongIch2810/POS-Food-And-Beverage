## Verification and limits

The [matrix](matrix.md) was written before running AC-1..8 and extended before AC-9 testing after Product Owner created S6-09. I reopened the TAP/list files, manual JSONL logs, DB output, browser snapshots/network parts and loading image before these verdicts. Each `PASS` above is tied to artifacts from this QA run on the tested working tree. The UI unit tests used mocks; browser mutations have separate live network and DB traces. No CI/independent runner artifact exists, so this is local verification only. Reproduction commands and exact start/end/exit data are in [run.md](run.md). The first `manual-extra.cjs` invocation failed in the evidence parser before test actions; its error and successful retry remain linked in run.md.

No observed AC mismatch needs an `errors/` record. QA scope does not include payment, idempotency, inventory deduction or sprint-level acceptance; those are outside PB-07. The static branch name shown in the app shell was not used as proof of selected branch; actual branch IDs came from API/DB artifacts.
